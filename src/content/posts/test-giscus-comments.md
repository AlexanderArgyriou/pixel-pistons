# Test Giscus Comments

This is a test post to validate the Giscus comments integration.

## Expected Behavior

If you see a Giscus widget below this content:
- ✅ Comments integration is working
- ✅ You can sign in with GitHub to comment
- ✅ The theme should match the blog (light/dark)

## How to Comment

1. Scroll to the bottom of this post
2. Click "Sign in with GitHub" in the Giscus widget
3. Authorize the Giscus app
4. Post your comment

Your comment will appear both here and in the GitHub Discussions for this repository.
